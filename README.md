# KGAR4Rec
## Knowledge-Grounded Agentic Reasoning for Explainable LLM-based Recommendation
Knowledge-Grounded Agentic Reasoning for Explainable  LLM-based Recommendation (KGAR4Rec), a three-agent framework consisting of an Analyst, a Recommender, and a simulated User with role-specific KG information assignment.
